# gateway/access/ — 对外界的权限鉴定

谁能进来。**网关自己判，不经过内核。**

| 文件 | 装什么 |
| --- | --- |
| `policy.py` | 来源分级 + 令牌校验 + 令牌的生成与复用 |

## 边界

- **不进内核**。这是接入面的知识（来源地址、令牌），内核不知道网络存在。
- **不处理 HTTP**。`web/http.py` 把它挂成一个路由依赖，把 401 和 `WWW-Authenticate` 头
  翻译出去——这一层不认识 FastAPI。
- **不装"谁在问"这个分类之外的东西**。`AccessLevel`（local / lan / external）是**判决的输入**，
  它住在这里；判决本身用 `permission/decision.py` 的三种词。
- 判断**不留内核事件**。来源只作为网关事件的字段（`principal_ref` / `access_mode` /
  `connection_ref`）被记下来，供审计查"哪些命令来自外网"。

## 判据

```python
judge([来源在信任网段, 令牌对不对], default="deny")
```

- **局域网（含回环）放行**。它就在你手边，和坐在机器前没有区别。
- **外网必须凭据**。凭据是这台机器自己生成、只存在本地的令牌——所以"能拿到它"等价于
  "你能接触这台机器"。
- 凭据与局域网**同权**。它是授权的证明，不是降级访问。真正的门是"从哪里来"，
  进来之后一视同仁。
- 令牌**总是自动生成**，不存在"忘了配"这个窗口。
- **解析不了一律算外网**——这就是"默认拒绝"在这里的样子：碰到看不懂的来源，
  宁可要求凭据，也不能当成可信。

判决翻译成 HTTP：`allow` → 放行；`deny` → 401 + `WWW-Authenticate`。

## 别踩回去的坑

uvicorn 默认信任来自回环的 `X-Forwarded-For`。本机一旦有反向代理，客户端地址就变成
攻击者可控，LAN 检查可以被伪造——所以外网部署必须 `--no-proxy-headers`。

另一条：权限检查必须挂成 **router 级依赖**，不是中间件。依赖跑在路由之后，所以不存在的
路径仍然是 404；中间件会把它变成 401，那既改变了对"这个接口不存在"的答复，
也让故意不存在的路由看起来像认证问题。
