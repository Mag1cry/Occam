# tests/ — 测的是「**用户能感受到的东西**」

两条判据，别的都只是手段：

1. **按下去真的生效了吗** —— 屏幕上那个按钮，用户期望发生的那件事**真的发生了**吗
2. **该显示的显示全了吗** —— 用户要看的那几样，是不是都在，是不是缺了一大块

**为什么用这个轴**：模块测试、契约测试、边界测试可以全绿，而用户点下去什么都没发生。
（这不是假想——下面每一行的"实测"都是**对着真后端按出来的**，九成的按钮现在是 400。）

**哪些是"感受到"**：按下按钮之后系统里的变化（能用重读证明）、屏幕上出现/消失的东西、
报错时用户读到的那句话。**哪些不是**：函数名、模块边界、内部字段——那些是手段，红了再修。

| 跑什么 | 命令 |
| --- | --- |
| 后端（242 条） | `uv run pytest -q` |
| 前端（238 条，在 `../../occ-command-center`） | `npm test` |
| **联调**（10 条，要真后端，默认跳过） | 见 `../../occ-command-center/src/api/live.test.ts` 头部 |
| **起一套来点** | 后端 `OCC_NEXT_ROOT=demo uv run python -m src.serve`；前端 `npm run dev` |

夹具在 [`support/`](support/)：`newtree.py` 是**最小可跑的一整个系统**（两个包 + 一条日程 +
一家供应商，worker 是真子进程），`newcore.py` 是内核的快捷动作，`mcpserver.py` 是说真协议的假 MCP 服务器。

## 二、内容：该显示的显示全了吗

**实测口径**：拿真后端的快照跑一遍投影，看该出现的节点/字段**在不在**。
空列表最容易骗人——它看起来像"还没有数据"，而不是"接错了"。

> **逐页的那一份在 [`../docs/review-qa.md`](../docs/review-qa.md) §二**：
> 五个页面各自显示哪些项、数据从快照的哪一块来、缺什么。这张表是按界面分的，那张是按页分的。

| # | 界面 | 用户要看 | 现在 | 缺什么 |
| --- | --- | --- | --- | --- |
| C1 | 世界场景 | 有哪些任务、各自什么状态、谁在跑 | **✓** 任务 + 状态 + 审批 + `controllers`（谁在跑） + 事实流 | — |
| C2 | 任务详情 | 它要干什么、干到哪了、**结果是什么** | 任务字段 + 最近事件 **✓**；结果 **✗** | 结果**归执行者的包**，要靠 adapter 读（新后端 `GET /api/tasks/{id}` 已按这条实现，但**一个测试都没有**；weather 没提供 adapter，所以它答"不提供结果查询"） |
| C3 | 智能体审计面板 | 模型这一路说了什么 | **✗ 404**（`GET /api/tasks/{id}/agent-audit` 新后端没有这条路由） | 要么补端点（也走 adapter 的 `read_audit`），要么这一段先不显示 |
| C4 | 配置舱 | 四个列表 + 开关 + 诊断 | **✓** 包 / 供给→工具 / 执行者 / 智能体 / 日程 / 供应商都在（含关着的那些），**每一类都有开关行**（供应商那一行是修 B7 时补上的） | 供应商节点上**只有名字，模型目录没画出来**（模型目录在新建智能体的选择器里看得见） |
| C5 | 配置舱 | 设备、MCP | **空** | 这两个概念没有了。空着不算错，但**用户分不清"这一类不存在了"和"现在没有"** |
| C6 | 日程场景 | 有哪些日程、跑过没有 | **✓** 日程 + 派发记录 | 「下次运行时间」没有——后端不算 `next_run`（记在 OPEN_ISSUES） |
| C7 | 全局 | 出错时那句人话 | **✓** 校验没过是 400 + 原因（用户能照着改） | 服务端自己炸是 500（不再是"其余一切 → 400"） |

### 内容怎么测

**内容测试**和按钮测试是同一个动作的两面：**拿真快照断言"该有的都在"**。
写成一条：`配置舱的节点数 > 0`、`每个包都有一个节点`、`关着的供给仍出现在列表里且标着已下线`。
——这类断言很笨，而它们抓的正是"接错了字段 → 界面上少一整块"。

## 四、写的时候的规矩

1. **用例名说人话**：`test_批准了甲不能执行乙` 比 `test_fingerprint_mismatch` 有用——
   半年后红的是哪一个、它本来保证什么，名字里就写着。
2. **一条只钉一件事**，且不依赖别的用例留下的状态（`newtree.application(tmp_path)` 每回都是干净的一份）。
3. **断言落在用户能感受到的东西上**（状态、答复、屏幕上的节点），不落在内部函数名上。
4. **联调那一层不能省**：桩测试证明"前端送了"，只有真后端能证明"真的生效"。

**还没有实现、所以先别写测试的**（都在 [`../src/OPEN_ISSUES.md`](../src/OPEN_ISSUES.md)）：
工具调用的执行审计、工具调用超时、错过的那一分钟不补派、事件链的保留与归档、设备那一整条线。
